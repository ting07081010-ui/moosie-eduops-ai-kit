# Moosi 說 · 離線示範 (Offline Demo)

第一條安全、離線、可執行的垂直切片：老師課後文字紀錄 → 課綱限定學習圖卡草稿 →
老師預覽 → 綁定內容雜湊的明確核准。**核准只更新本地草稿狀態，不會傳送訊息給家長。**

全程 synthetic 假資料、無外部呼叫、無付費服務。

## 執行

```bash
npm install
npm run demo:moosi-say
# 開啟瀏覽器前往 http://127.0.0.1:3107
```

伺服器只綁定 `127.0.0.1`（本機），不會對外監聽。Port 可用 `PORT` 環境變數覆寫。

## 操作流程

1. 從名單選擇學生（代號如 `S-007`，不可手打姓名；全部為 synthetic 資料）。
2. 在文字框輸入老師課後文字紀錄（**打字逐字稿，不是語音辨識**），或用「載入水果課範例」。
   範例情境：S-007 在 Unit 5 水果課能說出 apple 和 banana，grapes 的字首 g 還需要多練習；
   家長在家陪玩買水果遊戲，練習說 `I want some grapes, please.`。
3. 按「產生草稿預覽」：右側顯示 4:5 圖卡（SVG，viewBox `1080x1350`）、卡片 JSON 與 SHA-256 內容雜湊。
4. 確認內容後選核准身份（老師／管理員）再按「核准此版本」。
   核准會比對你預覽版本的雜湊：雜湊缺失、不符、草稿被阻擋或重複核准都會被拒絕。

## 什麼是假的（Mocked）

- **逐字稿**：直接輸入文字，沒有語音轉文字、沒有音檔處理。
- **圖卡內容**：固定樣板規則從逐字稿與課綱 JSON 組出，**不是 AI 生成**（卡片標示 `method: "rule-template"`）。
- **圖卡渲染**：SVG/HTML 預覽，不是 PNG 匯出；吉祥物只是簡單佔位圖形，無真實兒童圖像。
- **核准**：只把本地狀態設為 `approved`（`sent` 永遠是 `false`）；沒有 WhatsApp、沒有家長端。
- **學生與課綱**：`data/students.json` 3 位假學生、`data/unit5.json` 為 Unit 5 水果課白名單
  （單字 `apple, banana, grapes`；句型 `I want some {fruit}, please.`；發音重點為 grapes 字首 g 的練習，
  僅為課堂練習描述，不作能力判斷或成效承諾）。

## 安全規則（Fail-closed）

- 所有英文單字與句型必須來自 Unit JSON 白名單；超綱單字（如 orange）直接退回，不會靜默放行；也沒有向量資料庫。
- 卡片每個欄位都需有逐字稿依據（`evidence` 段落 ID）；缺依據就擋下，不編造。
- 核准綁定卡片內容的 SHA-256 雜湊：核准時以後端儲存的**當前卡片重新計算**雜湊，
  缺失／不符／被阻擋／重複核准一律拒絕；對外回傳的物件皆為深拷貝，外部竄改影響不了內部狀態。

## 自動化測試（皆離線、無網路呼叫）

```bash
npm test -- test/moosi-say-demo.test.mjs
```

涵蓋：合法產生（3 單字＋1 句型＋依據 ID、雜湊穩定）、超綱字拒絕、缺依據擋下、
雜湊綁定核准／竄改拒絕／重複與阻擋拒絕、回傳物件竄改無法繞過核准、4:5 SVG 渲染。
