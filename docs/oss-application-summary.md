# OSS Application Summary

Moosie EduOps AI Kit is not a generic tutoring app. It is an open-source
reference implementation for privacy-aware AI operations in small education
providers.

The project provides reusable prompts, JSON schemas, fake student data, a
runnable teacher-note CLI, a minimal LINE bot demo, evaluation sets,
privacy-risk checks, and AI-assisted maintainer workflows.

Its goal is to help small tutoring schools, solo teachers, church education
teams, nonprofits, and local learning programs adopt AI workflows responsibly
without exposing minors' learning data or building a full commercial education
management system.

## Reviewer Signals

- Public repository with MIT license
- Clear quick start and runnable CLI demo
- Fake and de-identified sample data only
- Privacy model for minors' learning data
- Eval cases for parent-message quality and privacy risk
- SECURITY, PRIVACY, CONTRIBUTING, issue templates, and PR checklist
- Tagged release line for reviewer-visible project maturity

## What This Is

- A workflow reference for teacher notes, parent summaries, task extraction, and
  risk checks
- A prompt / schema / eval starter kit for maintainers
- A privacy-first example for Traditional Chinese education contexts

## What This Is Not

- A CRM
- A payment system
- A grade book
- A student identity database
- A hosted SaaS product
- A replacement for teacher judgment or local legal review
